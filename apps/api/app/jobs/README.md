# 独立任务进程

同步、统计、评分、售后分析的入口在此实现，业务规则放 `app/modules` 并由 API 和任务共同调用。

M1手工入口为`sync_m1.py`，执行方式见根README，旧实现的代码和运行方式仅作历史参考；数据库重新设计期间暂停这些任务，设计流程见[用户流程](../../../../docs/database-design.md#database-design-process)。任务与API进程独立，无定时调度；API启动或用户刷新不触发数仓读取。其他任务按各域授权实施。

`resolve_profiles.py`仅解析已入库资料；`score_m1.py`仅导入经核四线或重算已入库新品，模型与分项存PG。评分计算与发布前分别核对相容输入，失败/中断/过期候选不替换上一有效结果；当前原值同步不隐式触发评分，更新后先pending，由显式评分任务完成重算。定时编排属于后续阶段。
