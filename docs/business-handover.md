# 拼多多运营看板交付说明与指标口径

更新日期：2026年11月4日。本文说明新版看板的使用变化、指标口径及数据更新规则。访问入口和正式启用时间以上线通知为准。

查阅入口：[本次变化](#changes) · [新旧差异](#differences) · [指标口径](#metrics) · [自查与反馈](#feedback)

## 1. 本次变化

本次调整统一各看板的数据说明和操作方式，明确统计期间、来源、更新状态及风险建议的依据，方便运营核对数字、定位需要关注的商品。

| 看板                         | 界面与操作变化                                                                                   | 数据、规则变化                                                            | 使用时需要注意                                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| 商品数据看板（含新品评分）   | 新品起势补充期间；风险清单可翻页查看全部，隐藏处理期限和状态；评分说明明确部分得分               | 新品起势统一按近7日；健康度按同款逐日配对；金额、买家数和件数不额外扣补单 | 健康度只代表可比同款；风险提醒不等于已确认问题或已派任务；部分得分不当作完整评分    |
| 商品推广看板（店铺推广总览） | 简化有无记录的提示；趋势增加竖线、圆点和点击固定，方便按天对比；日期不重叠，非负指标不显示负刻度 | 趋势按当天已有店铺记录计算，不因一家店无记录就让整天断线                  | 两个指标各用自己的刻度；无记录不补0，也不直接判断经营变差                           |
| 商品推广看板（商品推广明细） | 等级筛选增加“多等级”；来源简写“数仓”；摘要按有数据天数计数；诊断分清提醒与未评级                 | 多等级商品单独分组；缺项、真实0和未评级分别表达                           | 花费原值保留“—”，金额与比率按已提供值汇总；未评级不当零异常                         |
| 店铺销售看板                 | 页头和数据提示改为业务用语；退款计算、历史补充及地区缺项放入明细；评分趋势说明精简               | 目标完成率保留两位小数；卡片与说明沿用已确认来源和计算                    | 空值、没有记录和真实0分开看；目标按月份累计，经营指标和地区各按自己的日期、店铺统计 |
| 运营中心                     | 首页先看最多六项关注及对应建议；数据更新弹窗按来源列出具体表、网页入口、更新时间和同步结果       | 直接使用子看板风险与建议；数仓按固定时点检查网页更新，变化后同步对应来源  | 首页条数不是异常总数；建议不等于已派任务，未指定负责人显示待分配                    |

本文中“原版”指重构前的看板，“新版”指本次交付的看板；新旧入口切换安排以上线通知为准。
