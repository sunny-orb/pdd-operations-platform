# 数据与接口契约

状态：模板；业务字段、公式和唯一键尚未验收。先填写商品域，再逐域补全。

## 通用约定

| 项目     | 约定                                                             |
| -------- | ---------------------------------------------------------------- |
| ID       | 字符串，区分平台、店铺和来源记录；业务键不能只靠自增主键         |
| 业务日期 | `YYYY-MM-DD`，日界线默认 Asia/Shanghai，仍需对齐上游             |
| 时间戳   | ISO 8601，必须带时区                                             |
| 金额     | API 十进制字符串；单位在字段/契约说明，数据库 NUMERIC            |
| 比例     | 0—1；零分母通常为 null，具体业务确认，不能统一变零               |
| 空值     | 未提供/不可计算；缺记录与真实零成交分别表示                      |
| 查询     | 明确日期包含边界、筛选维度、稳定排序、页码/页大小上限            |
| 分页     | 后端完成；汇总和明细属于同一筛选范围、有效版本                   |
| 返回     | 正常 `data` + `meta`；错误 `error.code/message/request_id`       |
| 数据状态 | 来源、已观察范围、完整截至日期、上次成功时间、发布版本、缺失说明 |

## 单域填写模板

- 域名与业务用途：待填。
- 来源负责人、正式表/视图/API/文件：待填。
- 每行粒度、业务唯一键、来源 ID：待填。
- 必填字段、数值单位、精度、允许空值：待填。
- 更新频率、完成标记、延迟承诺、修改时间/CDC：待填。
- 删除、历史回补、重查窗口、归档和保留：待填。
- 指标公式与分母、同比映射、去重范围：待填。
- 接口参数、排序、分页、数据状态：待填。
- 与旧页面对账样例及已知差异：待填。
- 业务确认人、日期、规则版本：待填。

## 商品首条链路候选

候选粒度为平台 × 店铺 × 商品 × 日期，是否还需其他维度必须核实。交易额、访客、买家、订单、件数、收藏及去年字段由实际来源定义。不要在确认前重复做单扣减或把订单转化与买家转化混为一谈。

候选接口：`GET /api/v1/products/options`、`/summary`、`/trend`、`/daily`。它们目前未实现，初始化 OpenAPI 只提供系统与健康检查路由。
