# 前端请求与渲染性能

2026-10-31。本轮只调整本地前端加载与展示，不修改业务口径、来源、查询窗口或已发布数据。全看板API计时和总体验收记录另见[验证入口](../validation.md)。

## 瓶颈与实现

| 位置          | 可复现问题                                                                                          | 当前行为                                                                                                                                                                   |
| ------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 商品候选目录  | 总览和明细同版本、同条件仍分别请求；业务明细翻页改变目录查询键，但HTTP目录页码实际被`pageParam`覆盖 | 同条件总览/明细共用查询；目录页码与业务分页独立。评分仍按`score`独立取新品目录；不同筛选、已选商品、版本不共用                                                             |
| 推广总览/诊断 | 明细页码、页容量进入全部查询键，翻页会重查结果完全相同的总览、候选和诊断                            | 只有`days`消费业务分页；其他查询固定无关分页字段，保留日期、店铺、完整商品身份、品类、等级、运营等实际业务条件                                                             |
| 售后总览/目录 | 分析标签与页码改变总览、目录查询键，品类筛选也重取完全相同的报告目录                                | 只有`analysis`消费标签与分页；总览保留报告/品类/关键词/问题重点，目录只依赖报告与数据版本                                                                                  |
| 推广诊断清单  | 原生`details`关闭时，React仍渲染全部隐藏表格行；同一商品还出现在重点及全量清单中                    | 保留原生展开/键盘交互，关闭时卸载表格；展开后在完整响应上先搜索、再按25/50/100条分页。清单搜索覆盖对象身份、指标值、规则、证据、建议和说明；总数、服务端统计、原排序均保留 |

查询范围依据实际本地API消费字段核对：`product_board.options`只有`score`与其余目录不同；推广分页只用于`days`；售后`options`只读所选报告，`overview`不读取`view/page/size`。没有以删掉业务条件换取查询复用，也没有新增跨版本缓存或调整现有30秒新鲜度、45秒元信息轮询和409有界恢复。

## 本轮测量

环境：本机macOS 26.5.1 / arm64，Node.js v24.22.1；Codex内置浏览器默认视口1265×720；前端为本地Vite开发服务`127.0.0.1:5173`，数据来自本地已发布API。以下为同一实现改动前后的请求数和DOM工作量，不是生产首屏耗时或P95保证。

## 构建与限制

五页原已使用路由`lazy`；本轮保留。修改前生产入口JS为287.75kB（gzip90.90kB），共享最大块552.82kB（gzip180.17kB）。新增分页后，入口287.72kB（gzip90.87kB），共享最大块585.15kB（gzip188.93kB）；构建器将原表格块的分页依赖移入更多页面共用的块。本轮没有宣称包体积改善，也未修改警告阈值；共享块超过500kB的警告仍保留。

推广分页只减少浏览器挂载行数，仍接收完整诊断响应，未减少该接口传输体积。首次展开和每页切换需要绘制当前页；最大100行。全量API结果继续由负责域计算，不引入浏览器业务汇总、上游直连或样例回退。

本次不是线上新旧同条件性能验收，也未测正式环境并发、冷网速首屏、P95或长期内存。生产容量目标及共享上线门禁仍按[验证与验收](../validation.md)执行。
