# 商品数据看板：前端交付记录

2026-10-22。本次仅实现商品整页前端，未接入数据库/数仓/飞书，未调用AI或实现生产评分。用户已批准六块、头部热卖榜及真实字段/状态修正。

## 查看页面

- 启动：`npm run dev:web`（只启动前端）。
- 默认：`http://127.0.0.1:5173/products`，展示未接入状态，不请求经营数据。
- 开发样例：`http://127.0.0.1:5173/products?preview=1`，页首持续标“开发样例·非真实经营数据”。
- 工具条可切正常、缺数、空结果、失败、评分/诊断待生成和未接入场景。工具条仅开发环境可用，生产禁止启用样例；接口失败不回退样例。

## 代码职责

| 位置（`apps/web/src/features/products/`下） | 职责                                                   |
| ------------------------------------------- | ------------------------------------------------------ |
| `ProductsPage.tsx`                          | 页面组合、三个URL范围、数据版本与开发入口              |

| `sections/`                                 | 六块展示，Ant Design控件；Recharts趋势/告警小图        |
| `products.css`                              | 商品页局部布局/视觉，不扩散到其他业务路由              |

## 后续接数据

1. 先确认来源、日期/金额/归因及实际唯一键；按 `m1-api-and-postgresql.md` 对接后端。
2. 后端提供规范响应，在开发环境通过 `?data=api` 验证只读接口；未实现的路由明确错误，不能当作无数据。
3. 响应字段通过Zod校验；金额字符串、比例0—1、缺数null；三套筛选独立，数据版本统一。
4. 真实计算在后端：汇总/同比/评分/告警；AI只生成有证据的文案。前端样例适配不是生产ETL或评分模型。
