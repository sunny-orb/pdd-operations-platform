## 2. 通用展示与交互

- 每个区块显示实际范围、完整截至日期、最近成功更新时间和来源更新状态；不同来源日期分别显示。请求成功不能表述为数据完整最新。
- 金额、比例、日期、唯一键和业务公式以 [数据契约](data-contract.md) 为准。金额用十进制字符串、通常占比0—1（增长率/ROI例外）、ID字符串、日期按明确业务日及Asia/Shanghai解释；前端只格式化，不另算正式指标。
- 汇总、同比、评分、告警和影响估算由后端依确认规则提供；上游已有正确公式不重复扣减。规则诊断与AI生成分别标识，AI文案必须有依据和日期。
- 后续M1前端字段可直接按已确认后端契约调整，不要求维持旧草案兼容层。样例适配和旧发布字段均不能反向约束最终契约。
- 筛选有标签、范围说明和重置；无效日期不得静默发请求。作用域、级联和日期联动按各模块规则，不能以全局联动覆盖独立条件。
- 新筛选取消旧请求或阻止过期结果覆盖；切条件时不把旧范围内容显示成新结果。同条件刷新可保留旧值并明确更新状态。
- 同一模块的当前经营结果使用兼容数据版本。切版时协调撤下或遮罩旧结果并重取，不能混用新旧批次；重复冲突停止自动循环并提供重试。
- 默认不展示经营样例。开发样例须持续标识“开发样例·非真实经营数据”，少量人工合成且仅开发启用；接口失败不得回退样例，生产不得自动启用。
- 页面按需说明业务来源，不暴露凭据、敏感连接或内部调试信息。公共导航和页面目录应可键盘操作，长表局部滚动，窄屏无整页横向溢出。

| 状态              | 展示要求                                                    |
| ----------------- | ----------------------------------------------------------- |
| 尚未接入          | 保留区块和标题，显示未接入；指标为“—”，无假曲线、假完成时间 |
| 首次加载          | 区块骨架；不遮挡其他可用区域，不使用虚构进度                |
| 无匹配结果        | 说明当前筛选无结果，允许清除本区条件；与未接入分开          |
| 真实零值          | 正常显示0，不当作空、缺数或错误                             |
| 部分缺数/不可计算 | 有依据的值保留，缺项“—”并标原因；同比缺去年值不显示0%       |
| 陈旧或刷新失败    | 同条件旧值可保留，明确日期及更新失败；不声称最新            |
| 请求失败/契约错误 | 区块错误与重试；404、网络错误、非法响应不转换成无数据       |
| 评分/诊断未生成   | 显示未计算、待生成、失败或缺项原因，不影响基础经营数据      |
| 人工闭环未启用    | 状态和期限显示“尚未启用/—”，不伪造待处理任务                |

### 每次交付怎样拆分，页面样式以什么为准

每次选一条完整操作来交付，例如“选店铺和日期，查看指标并定位明细”。写清涉及哪些区块、数据和接口、已有能力要保留什么、未决项影响哪里，以及怎样检查结果。数据、业务计算和页面一起验证；不要求先做完全部公共组件再开始业务页面。

页面外观仍以指定线上原型和已确认调整为准。实施前选定该页要支持的浏览器、视口、缩放、字体和网络条件，沿用第9节的对照要求；未确定的环境列待确认。先检查骨架在这些尺寸下能否正常排列，再接入图表和真实状态。

公共颜色、字号、间距等设计变量（design tokens）在共享样式中集中维护，使用既定组件和图表库。同类导航、筛选、指标卡、表格和图表先复用；新业务确有差异可以增加组件和规则，不强行把所有页面写成配置。局部主题不得污染其他页面，偏离原型或公共样式须记录原因及确认结果。

一个功能完成后按[交付验收条件](validation.md#delivery-gates)检查。未通过的内容不进入对外发布；不依赖它的已授权工作可以继续，不能把单项缺口变成全项目停工理由。

## 4. M4 新品评分专项

M4属于M1商品页内功能，当前整页范围已包含其展示，不再以“独立模块未开工”为由排除。专项用于确认适用新品范围、评分输入、表现档位、阈值解释和放量建议。

先核对当前线上算法及可追溯输入，再讨论改模型；旧V4/V5脚本、模型文件名和历史输出不是现行算法证明。缺历史、缺推广、零分母或批次不兼容时应明确不可评分/待验证，不虚构分数。

评分不以取得旧生成源码为前置：十指标、权重、四档判分和已有数值标准可直接实现；已有标准保留出处、日期和适用范围，缺适用标准只影响对应项。上架日期缺失由技术侧明确显示缺失与观察依据，不删除商品或编造上市阶段；具体处理及新增参照组的试行方案见契约3.5.1。页面旧得分不直接搬成新库当前得分。

分数、解释和建议关联规则版本、输入批次及日期；重跑与切版可追溯。数值评分不依赖大语言模型；AI解释是否启用另按服务和业务确认。展示样例通过不代表规则和真实评分通过。
