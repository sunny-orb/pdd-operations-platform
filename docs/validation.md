| 基线 | 固定哪些条件                                                                                        | 留下什么结果                                                                                           |

| 数据 | 核心指标、公式版本、店铺/商品/日期、单位/分母、资料视角、权限、输入来源/版本与覆盖。                | 可执行的核对步骤、预期值与实际值、差异及容差依据、刷新规律、延迟、上游依赖和口径歧义。                 |
| 使用 | 统计期间、获准日志或访谈方法、真实角色及数据可见范围。                                              | 各页访问频次、常用筛选与下钻路径、导出/汇报等真实用途；没有证据的“无人使用”判断不得登记为事实。        |

每份基线包记录代码及资源版本、环境、输入标识、可重复执行的命令/步骤、预期与实际结果、报告/截图位置、日期和执行/确认人。记录版本号不代表保存了当时数据：输入会被覆盖时，先确定获准的样例、来源版本或备份能否重建；不能复现原数值的地方明确标注。

无敏感数据的测试代码、合成样例和执行说明可随代码维护；真实经营输入、日志和截图放获准的私有验收目录，记录引用及校验值，禁止把整套旧快照搬进仓库或新查询主链路。尚未编写的复测脚本、尚未采集的日志均保持待办，本文不表示基线包已存在。
