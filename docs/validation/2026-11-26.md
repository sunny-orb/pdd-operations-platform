## 正式网页验收

Chrome 实测五页真实模型，以下耗时从发送操作至完整响应取得，包含页面筛选等待，不代表正文首字时间。

| 页面与问题                     | 模型请求／工具次数 | 完成耗时 | 核对结果                                                     |
| ------------------------------ | ------------------ | -------- | ------------------------------------------------------------ |
| 运营中心，最近七天整体经营     | 2／4               | 14.86秒  | 销售、推广、商品风险及售后分别标注期间，有实际数字及核查建议 |
| 商品，当前期间哪些款有经营风险 | 2／1               | 6.00秒   | 对应实际规则命中和商品身份                                   |
| 销售，本月GMV目标完成多少      | 0／0               | 1.39秒   | 直接读取六店渠道目标及已发布进度，未编造单店目标             |
| 推广，当前期间花费与投产       | 2／1               | 3.59秒   | 正确使用当前页期间，能区分渠道与净口径缺项                   |
| 售后，报告情况及先处理哪款     | 2／1               | 4.41秒   | 采用报告实际期间、单款风险及动作依据                         |

另外实际选择两款商品，连续问“这款”，再明确回问第一款推广，均按对应链接与店铺取数。所有店铺月销售问题没有被当前单款缩小。关闭跟随、切页、恢复跟随、保留草稿与聊天、商品总览及逐日明细选款、五页导航和390px窄屏均核对实际请求。

上线验收发现并修复两项问题。页面筛选尚未就绪时先保留输入，避免空范围提交；进入全局模式仍可发送。模型表格的百分比由程序格式化，例如原始退款率1.410445显示141.04%，原始报告保持精确值。真实模型复测通过。

四域接口与上一运行版本在同一当前输入及范围下对照，商品、推广、销售、售后响应数据一致。临时容器只读执行后自动删除。

旧页面保留到发布后继续切换五页，无脚本加载错误。发布持续HTTP探测662次均200，原始记录保存在本机忽略目录 `var/audits/release-20261125`。本机前端573项、相关后端专项、检查与构建通过，最终代码另外通过云端全量回归。
